============================================================
  UK Planning Scraper - How to Run
============================================================

PREREQUISITES
------------------------------------------------------------
  - Ruby 3.1+ with Devkit (https://rubyinstaller.org)
  - Node.js 18+ (https://nodejs.org)
  - Bundler gem:  gem install bundler

QUICK START
------------------------------------------------------------
  1.  bundle install
  2.  bundle exec ruby scrape.rb

  Or double-click:  run.bat

  The scraper automatically:
    - Detects which playwright-core version the Ruby gem needs
    - Installs that matching playwright-core via npm (if missing)
    - Installs the correct Chromium revision (if missing)
    - Starts scraping

  You do NOT need to manually install browsers.
  You do NOT need to match versions yourself.

============================================================

HOW IT WORKS (technical detail)
------------------------------------------------------------
  The Ruby gem (playwright-ruby-client) does not bundle a Node CLI.
  It needs an external `playwright-core` Node package whose version
  matches the gem's COMPATIBLE_PLAYWRIGHT_VERSION constant.

  lib/uk_planning_scraper/playwright_compat.rb handles this:
    1. Loads the Ruby gem
    2. Reads COMPATIBLE_PLAYWRIGHT_VERSION (e.g. "1.44.0")
    3. Checks which playwright-core is installed in node_modules
    4. If mismatched, runs: npm install playwright-core@<version>
    5. Sets CLI_EXECUTABLE_PATH to node_modules/.bin/playwright-core

  This means the gem and Node CLI are ALWAYS version-aligned,
  regardless of which gem version is installed.

============================================================

TROUBLESHOOTING
------------------------------------------------------------

ERROR: "Executable doesn't exist at ...chromium-XXXX\chrome.exe"
------------------------------------------------------------
  The Ruby gem and Node playwright-core are mismatched.

  The scraper should auto-fix this. If it doesn't:
    1. Delete the browser cache:
         rmdir /s /q "%USERPROFILE%\AppData\Local\ms-playwright"
    2. Delete node_modules and reinstall:
         rmdir /s /q node_modules
         npm install
    3. Run the scraper:
         bundle exec ruby scrape.rb

  The scraper will detect the gem's version, install the matching
  playwright-core, and download the correct Chromium.

ERROR: "Could not locate Gemfile"
------------------------------------------------------------
  Your folder path has spaces or parentheses. Make sure you:
    - cd to the project folder first:  cd /d "I:\ukplanningscraper (newest update)"
    - Then run:  bundle exec ruby scrape.rb
  run.bat handles this automatically with setlocal and %~dp0.

ERROR: "timeout: expected float, got undefined"
------------------------------------------------------------
  Same root cause as "Executable doesn't exist" — the gem and
  Node CLI are subtly mismatched. Follow the same fix steps above.

ERROR: "Failed to download Chromium ... INSTALLATION_COMPLETE does not exist"
------------------------------------------------------------
  The download from the CDN failed. This can happen with:
    - Network/proxy issues
    - Antivirus blocking the download
    - Partial download left behind

  Fix:
    1. Delete the partial download:
         rmdir /s /q "%USERPROFILE%\AppData\Local\ms-playwright\chromium-1076"
         (or whichever revision number is shown)
    2. Retry:  bundle exec ruby scrape.rb

  If it keeps failing, try a different network connection or
  disable antivirus temporarily for the download.

Empty results vs. failures:
  - The scraper distinguishes between:
      * A council with no matching applications (empty but successful)
      * A council that could not be reached (recorded as failed)
      * A council whose browser could not start (recorded as failed)
  - Failed councils are written to retry_authorities.csv with the
    actual error, and are retried automatically at the end of the run.
  - A final summary shows successful councils, empty results, and
    failures separately.

============================================================

MANUAL VERSION ALIGNMENT (if auto-detection fails)
------------------------------------------------------------
  1. Find the gem's compatible version:
       bundle exec ruby -e "require 'playwright'; puts Playwright::COMPATIBLE_PLAYWRIGHT_VERSION"
  2. Install that exact playwright-core:
       npm install playwright-core@<version>
  3. Install Chromium:
       node_modules\.bin\playwright-core install chromium
  4. Run the scraper:
       bundle exec ruby scrape.rb
