============================================================
  UK Planning Scraper - How to Run
============================================================

STEP 1: Delete the vendor/bundle folder (fixes permission + path issues)
-----------------------------------------------------------------------
  - Close any terminals, Cursor, or programs using this project
  - Delete this folder: vendor\bundle
  - (The project folder name has spaces/parentheses which breaks native
    gem builds. Using system gems avoids that.)

STEP 2: Install gems (one-time)
-----------------------------------------------------------------------
  cd "D:\ukplanningscraper (newest update)"
  bundle install

  Gems install to your Ruby directory (C:\Ruby31-x64\...), not the project.
  This fixes the http_parser.rb build error.

STEP 3: Install Playwright Chromium (one-time, for Ocella/Arcus councils)
-----------------------------------------------------------------------
  IMPORTANT: Unset PLAYWRIGHT_BROWSERS_PATH first if it's set:
    set PLAYWRIGHT_BROWSERS_PATH=

  Then run:
    npx playwright install chromium

  Requires Node.js (https://nodejs.org). Downloads ~150MB.
  Browsers install to default cache (%USERPROFILE%\AppData\Local\ms-playwright).

STEP 4: Run the scraper
-----------------------------------------------------------------------
  bundle exec ruby scrape.rb

  Or double-click: run.bat

============================================================

Playwright "Executable doesn't exist" - fix:
  - scrape.rb now clears PLAYWRIGHT_BROWSERS_PATH so Playwright uses its default cache
  - Run in a NEW terminal: set PLAYWRIGHT_BROWSERS_PATH=
  - Then: npx playwright install chromium
  - If PLAYWRIGHT_BROWSERS_PATH is in System/User env vars, remove it via
    Control Panel → System → Advanced → Environment Variables

If you still get errors:
  - Rename the project folder to remove spaces: "ukplanningscraper"
  - Ensure Ruby+Devkit was used (not plain Ruby) - needed for native gems
  - Run bundle install from an Administrator command prompt if permissions fail
